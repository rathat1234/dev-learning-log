# C++ 기초 복습

## 소스 파일에서 실행 파일까지

- **컴파일**은 소스 파일을 번역해 목적 파일을 만든다. 선언과 호출의 형식이 맞는지도 이 과정에서 검사한다.
- **링크**는 목적 파일과 라이브러리를 연결한다. 선언한 함수의 정의를 찾을 수 없다면 링크 단계에서 오류가 날 수 있다.
- `std::cout`의 `std`는 표준 라이브러리의 이름 공간이다. `::`는 이름이 속한 범위를 지정하며, 클래스 밖에서 멤버 함수를 정의할 때도 사용한다.

## 콘솔 입력과 문자열

`std::cin >>`는 공백으로 구분된 값이나 단어를 읽고, `std::getline`은 줄바꿈까지 읽는다. 두 방식을 섞을 때는 입력 위치를 확인한다. 아래 예제에서는 첫 줄에서 정수 하나를 읽은 뒤, 그 줄의 나머지를 버리고 다음 줄 전체를 읽는다.

```cpp
#include <iostream>
#include <limits>
#include <string>

int main() {
    int quantity{};
    if (!(std::cin >> quantity)) {
        return 1;
    }

    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

    std::string label;
    if (std::getline(std::cin, label)) {
        std::cout << quantity << " - " << label << '\n';
    }
}
```

첫 줄에 `3`, 다음 줄에 `blue notebook`을 입력하면 `3 - blue notebook`이 출력된다. 문자 배열에 한 줄을 읽을 때는 버퍼 크기를 넘겨주는 `std::cin.getline(buffer, 크기)`를 사용한다.

## 클래스와 객체

- **클래스**는 상태를 담는 멤버 변수와 동작을 정의하는 멤버 함수를 묶은 타입이다. 같은 클래스로 만든 객체도 각자의 상태를 가진다.
- **캡슐화**는 내부 상태를 `private`에 두고 필요한 동작을 `public`으로 제공하는 방식이다. `protected`는 파생 클래스에서 사용할 멤버를 지정할 때 쓰인다.
- **생성자**는 객체를 만들 때 상태를 초기화한다. 이름은 클래스 이름과 같고 반환형을 적지 않는다.
- **상속**은 기존 클래스를 바탕으로 새 클래스를 만드는 방법이다. **오버라이딩**은 파생 클래스에서 기반 클래스의 가상 함수를 다시 정의하는 동작이다.
- **오버로딩**은 같은 이름의 함수를 서로 다른 매개변수 목록으로 정의하는 방법이다. **템플릿**은 여러 타입에 적용할 함수나 클래스를 하나의 틀로 작성하는 데 쓰인다.

## 연습 · 독립적으로 동작하는 카운터

`counter.h`에는 클래스 정의와 멤버 함수 선언을 둔다.

```cpp
#ifndef COUNTER_H
#define COUNTER_H

class Counter {
public:
    explicit Counter(int initial);
    void increment();
    int value() const;

private:
    int value_;
};

#endif
```

`counter.cpp`에는 멤버 함수의 구현을 둔다.

```cpp
#include "counter.h"

Counter::Counter(int initial) : value_(initial) {}

void Counter::increment() {
    ++value_;
}

int Counter::value() const {
    return value_;
}
```

`main.cpp`에서는 객체를 만들어 공개된 함수로 사용한다.

```cpp
#include <iostream>
#include "counter.h"

int main() {
    Counter first{2};
    Counter second{8};

    first.increment();
    std::cout << first.value() << ' ' << second.value() << '\n';
}
```

출력은 `3 8`이다. `increment()`를 호출한 객체의 값만 바뀐다.
