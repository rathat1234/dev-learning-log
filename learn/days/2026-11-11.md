# 2026년 11월 11일 C++ 수업 정리

## 생성자와 멤버 초기화

- **생성자**는 객체를 만들 때 호출된다. 이름은 클래스 이름과 같고 반환형을 적지 않는다. 매개변수 목록을 달리해 오버로딩할 수 있다.
- **기본 생성자**는 인수 없이 호출할 수 있는 생성자다. 생성자를 하나도 선언하지 않으면 컴파일러가 기본 생성자를 암시적으로 선언한다. `Circle(int radius)`만 선언한 상태에서 `Circle donut;`도 사용하려면 인수 없이 호출할 수 있는 생성자를 마련해야 한다.
- **멤버 초기화 리스트**는 생성자 본문이 실행되기 전에 멤버를 초기화한다. `Point(int x, int y) : x_(x), y_(y) {}`처럼 쓴다. 멤버는 초기화 리스트에 적은 순서와 관계없이 클래스에 선언된 순서대로 초기화된다.
- **위임 생성자**는 같은 클래스의 다른 생성자에 초기화를 맡긴다. `Circle() : Circle(1) {}`에서는 `Circle(int)`가 실행된 뒤 `Circle()`의 본문이 실행된다. 여러 생성자가 공유하는 초기화 코드를 한 곳에 둘 수 있다.

## 소멸자와 객체의 수명

소멸자는 객체의 수명이 끝날 때 호출되며 `~Circle()`처럼 쓴다. 반환형과 매개변수가 없다. 파일을 닫는 등 객체가 소유한 자원을 정리할 수 있다. 직접 선언하지 않아도 컴파일러가 소멸자를 암시적으로 선언하며, 객체가 소멸할 때 멤버 객체의 소멸자도 호출된다.

| 객체 | 생성과 소멸 시점 |
| --- | --- |
| 일반 지역 객체 | 선언에 도달하면 생성되고, 블록을 벗어날 때 생성의 역순으로 소멸한다. |
| 전역 객체 | 수업 예제의 전역 객체는 `main()` 전에 생성되고 프로그램이 정상 종료할 때 소멸한다. 같은 소스 파일에 있는 일반 전역 객체는 정의 순서대로 생성된다. |
| `new`로 만든 객체 | `new`로 생성되고 대응하는 `delete`를 실행하면 소멸한다. 동적 할당 실습은 다음 시간 범위다. |

예를 들어 `main()`에 `Circle donut;`과 `Circle pizza{30};`을 차례로 선언하면, `main()`을 벗어날 때 `pizza`, `donut` 순서로 소멸한다. 생성자와 소멸자에 반지름을 출력해 호출 순서를 확인할 수 있다.

## 접근 지정자와 인라인 함수

| 지정자 | 접근 가능한 곳 |
| --- | --- |
| `public` | 클래스 내부와 외부 |
| `private` | 해당 클래스의 멤버와 `friend` |
| `protected` | 해당 클래스와 파생 클래스의 멤버 및 각 클래스의 `friend` |

접근 지정자를 생략하면 `class`는 `private`, `struct`는 `public`이 기본이다. C++에서는 둘 다 생성자와 멤버 함수를 가질 수 있다. `Rectangle` 실습에서는 너비와 높이를 `private`에 두고, 외부에서 값을 바꿀 때 공개 멤버 함수인 `setSize()`를 호출한다.

헤더에 둔 클래스 정의 안에서 함수를 구현하면 암시적으로 `inline`이 된다. 컴파일러가 호출 위치에 함수 본문을 펼치면 호출 비용을 줄일 수 있지만, 실제로 펼칠지는 최적화 과정에서 결정한다. 여러 호출 위치에 본문이 들어가면 실행 코드가 커질 수 있다.

## 실습 1 · 사각형 클래스와 파일 분리

`Rectangle.h`에 클래스 정의를 둔다. 헤더 가드는 여러 경로로 같은 헤더를 포함하더라도 한 소스 파일을 컴파일할 때 정의가 중복되는 것을 막는다. 수업에서는 `#pragma once`도 살펴봤다.

```cpp
#ifndef RECTANGLE_H
#define RECTANGLE_H

class Rectangle {
public:
    Rectangle();
    explicit Rectangle(int length);
    Rectangle(int width, int height);

    int getArea() const;
    bool isSquare() const { return width_ == height_; }
    void setSize(int width, int height);

private:
    int width_;
    int height_;
};

#endif
```

`Rectangle.cpp`에서 클래스 밖에 멤버 함수를 정의할 때 `Rectangle::`을 붙인다. 세 생성자 중 두 개가 너비와 높이를 받는 생성자에 초기화를 위임한다.

```cpp
#include "Rectangle.h"

Rectangle::Rectangle() : Rectangle(1, 1) {}
Rectangle::Rectangle(int length) : Rectangle(length, length) {}
Rectangle::Rectangle(int width, int height) : width_(width), height_(height) {}

int Rectangle::getArea() const {
    return width_ * height_;
}

void Rectangle::setSize(int width, int height) {
    width_ = width;
    height_ = height;
}
```

`main.cpp`에서 헤더를 포함하고, 빌드할 때 두 `.cpp` 파일을 함께 컴파일하고 링크한다.

```cpp
#include <iostream>
#include "Rectangle.h"

int main() {
    Rectangle unit;
    Rectangle square{3};
    Rectangle rect{3, 5};

    std::cout << unit.getArea() << ' ' << square.getArea() << ' '
              << rect.getArea() << '\n';
    std::cout << std::boolalpha << rect.isSquare() << '\n';

    rect.setSize(3, 3);
    std::cout << rect.isSquare() << '\n';
}
```

첫 줄에는 `1 9 15`가 출력된다. `rect`의 정사각형 판정은 `3 × 5`일 때 `false`, `3 × 3`으로 바꾼 뒤 `true`다.

## 객체 포인터와 배열

- **객체 멤버 접근**은 `donut.getArea()`처럼 `.`을 쓴다. `Circle* ptr = &donut;`처럼 객체 주소를 저장했다면 `ptr->getArea()`를 쓴다. `ptr->getArea()`와 `(*ptr).getArea()`는 같은 표현이다.
- **1차원 객체 배열**에서 `Circle circles[3];`은 원소마다 기본 생성자를 호출한다. `Circle circles[]{Circle{10}, Circle{20}, Circle{}};`처럼 원소별로 초기화할 수도 있다.
- **1차원 배열을 함수에 전달**하면 배열 이름은 첫 원소를 가리키는 포인터로 변환된다. 포인터 매개변수에 `sizeof`를 적용하면 포인터 자체의 크기를 얻으므로, 원소 개수를 별도로 넘긴다. 반복문에서 `circles[i].getArea()`와 `(circles + i)->getArea()`는 같은 원소에 접근한다.
- **2차원 배열을 함수에 전달**할 때 `Circle grid[2][3]`의 첫 원소는 `Circle` 3개로 이루어진 한 행이다. 따라서 `const Circle (*rows)[3]`으로 받는다. 함수 매개변수에서 `const Circle rows[][3]`으로 적어도 같은 타입으로 조정된다. `rows + 1`은 다음 행을 가리킨다.
- **배열 포인터**인 `Circle (*row)[3]`은 한 행을 가리킨다. **포인터 배열**인 `Circle* pointers[3]`은 객체 주소를 세 개 저장할 수 있다.
- **참조**는 기존 객체의 별명이다. 원 하나를 읽는 함수는 `const Circle&`로 받아 객체 복사 없이 `.`으로 멤버에 접근할 수 있다.

## 실습 2 · 원 배열의 넓이 출력

```cpp
#include <cstddef>
#include <iostream>

class Circle {
public:
    Circle() : Circle(1) {}
    explicit Circle(int radius) : radius_(radius) {}

    double getArea() const { return 3.14 * radius_ * radius_; }

private:
    int radius_;
};

void printAreas(const Circle* circles, std::size_t count) {
    for (std::size_t i = 0; i < count; ++i) {
        if (i != 0) {
            std::cout << ' ';
        }
        std::cout << circles[i].getArea();
    }
    std::cout << '\n';
}

void printGrid(const Circle (*rows)[3], std::size_t rowCount) {
    for (std::size_t row = 0; row < rowCount; ++row) {
        printAreas(rows[row], 3);
    }
}

int main() {
    Circle circles[]{Circle{10}, Circle{20}, Circle{}};
    Circle grid[2][3]{
        {Circle{1}, Circle{2}, Circle{3}},
        {Circle{4}, Circle{5}, Circle{6}}
    };

    printAreas(circles, sizeof(circles) / sizeof(circles[0]));
    printGrid(grid, sizeof(grid) / sizeof(grid[0]));
}
```

```text
314 1256 3.14
3.14 12.56 28.26
50.24 78.5 113.04
```

`main()`에서 `sizeof(grid)`는 배열 전체 크기이고 `sizeof(grid[0])`은 한 행의 크기이므로, 둘을 나누면 행 수인 `2`가 나온다. `printGrid()`의 `rows`는 행을 가리키는 포인터이므로 행 수는 `rowCount`로 받는다.
