## 동적 메모리 할당과 객체 배열

실행 중에 입력받은 개수만큼 공간이 필요할 때 `new`를 사용한다. 예를 들어 점수 개수 `count`를 입력받아 `new int[count]{}`로 정수 배열을 만들고, 각 점수를 저장해 합계를 계산할 수 있다. 할당에 성공하면 `new T`는 객체를, 원소가 있는 `new T[count]`는 배열의 첫 원소를 가리키는 포인터를 반환한다.

| 용도 | 할당 예 | 해제 |
| --- | --- | --- |
| 정수 하나 | `int* p = new int{5};` | `delete p;` |
| 정수 배열 | `int* scores = new int[count]{};` | `delete[] scores;` |
| 원 객체 하나 | `Circle* p = new Circle{radius};` | `delete p;` |
| 원 객체 배열 | `Circle* circles = new Circle[count];` | `delete[] circles;` |

- `new Circle[count]`는 원소마다 기본 생성자를 호출한다. `delete[] circles`는 생성의 역순으로 소멸자를 호출한다. 배열 원소에는 `circles[i].setRadius(radius)` 또는 `(circles + i)->setRadius(radius)`로 접근한다.
- `new`와 `delete`, `new[]`와 `delete[]`를 짝지어 쓴다. 짝이 맞지 않거나 이미 해제한 주소를 다시 사용하면 정의되지 않은 동작이 발생한다.
- 해제 후에도 포인터 변수는 자동으로 `nullptr`로 바뀌지 않는다. 포인터 변수를 계속 쓴다면 해제 직후 `p = nullptr;`로 값을 바꿀 수 있다. 같은 주소를 가리키던 다른 포인터로도 해제된 객체에 접근할 수 없다.
- 기존 할당을 해제하기 전에 주소를 덮어써 마지막 소유 포인터를 잃으면 메모리 누수가 생긴다. 반복문에서 같은 포인터에 `new` 결과를 계속 대입할 때 특히 주의한다.
- 일반 `new`는 메모리 할당에 실패하면 `std::bad_alloc` 예외를 던진다. `new (std::nothrow)`를 사용한 경우에는 할당 실패를 `nullptr`로 확인할 수 있다.

Visual Studio에서는 중단점을 걸고 포인터 값 `p`, 포인터 변수 자체의 주소 `&p`, 가리키는 값 `*p`를 비교했다. 메모리 창에서 정수 `5`가 `05 00 00 00`으로 보이는 것은 실습 환경에서 낮은 주소에 최하위 바이트를 저장하기 때문이다.

## `this`와 참조 반환

`this`는 현재 멤버 함수를 호출한 객체를 가리킨다. `this->radius = radius;`에서 왼쪽은 멤버, 오른쪽은 매개변수다. 정적 멤버 함수에는 `this`가 없다. 반환형이 `Circle&`인 멤버 함수에서 `return *this;`를 쓰면 같은 객체에 멤버 함수 호출을 이어갈 수 있다.

### 실습 · 원의 넓이와 연속 호출

수업 캡처처럼 정수 반지름을 반복해서 읽고, 원 객체를 동적으로 생성해 넓이를 출력한 뒤 해제한다. 음수를 입력하면 종료한다. 마지막 두 줄은 반지름 5에 1, 2, 3을 차례로 더하는 참조 반환 예제다.

```cpp
#include <iostream>

class Circle {
public:
    explicit Circle(int radius = 1) : radius(radius) {}

    void setRadius(int newRadius) {
        this->radius = newRadius;
    }

    double getArea() const {
        return 3.14 * radius * radius;
    }

    int getRadius() const {
        return radius;
    }

    Circle& plus(int amount) {
        radius += amount;
        return *this;
    }

private:
    int radius;
};

int main() {
    int radius{};
    while (std::cin >> radius && radius >= 0) {
        Circle* p = new Circle{radius};
        std::cout << p->getArea() << '\n';
        delete p;
    }

    Circle a{5};
    std::cout << a.plus(1).plus(2).plus(3).getRadius() << '\n';
}
```

입력이 `2 3 -1`이면 `12.56`, `28.26`, `11`이 한 줄씩 출력된다. 객체 배열 실습에서는 입력 개수만큼 원을 만든 뒤 `setRadius()`로 각 반지름을 저장하고, 넓이가 지정 범위에 드는 원의 개수를 센 다음 `delete[]`로 배열을 해제했다.

## `std::string`과 문자열 실습

| 표현 | 동작 |
| --- | --- |
| `std::cin >> text` | 공백으로 구분된 단어 하나를 읽는다. |
| `std::getline(std::cin, text)` | 공백을 포함해 줄 전체를 읽는다. |
| `text.size()`, `text.length()` | 현재 문자열의 `char` 원소 개수를 반환한다. |
| `text.capacity()` | 재할당 없이 저장할 수 있는 원소 수를 반환한다. 용량과 증가 방식은 구현에 따라 달라진다. |
| `text += suffix`, `text.append(suffix)` | 문자열 뒤에 내용을 붙인다. |
| `a < b`, `a == b` | 사전식 순서와 동등 여부를 비교한다. |
| `std::stoi(text)`, `text.c_str()` | 각각 문자열을 정수로 변환하거나 C 문자열을 가리키는 `const char*`를 얻는다. |

문자열 여러 개를 입력받아 사전식 순서에서 가장 뒤에 오는 문자열을 찾았다. 이어서 공백을 포함한 한 줄을 읽어 맨 앞 문자를 뒤로 보내는 왼쪽 회전을 실습했다. 한 바퀴를 돌면 원래 문자열로 돌아온다.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string text;
    if (!std::getline(std::cin, text)) {
        return 1;
    }

    for (std::string::size_type i = 0; i < text.size(); ++i) {
        const char first = text.front();
        text.erase(0, 1);
        text.push_back(first);
        std::cout << text << '\n';
    }
}
```

`abc`를 입력하면 `bca`, `cab`, `abc`가 한 줄씩 나온다. 이 예제는 `char` 단위로 회전하므로 UTF-8 한글은 글자 중간에서 잘릴 수 있다. 같은 입력 스트림에서 `>>` 다음에 `getline`으로 다음 줄을 읽으려면 앞 입력에 남은 줄바꿈을 먼저 소비한다.

## 값, 포인터, 참조로 함수에 전달하기

| 함수 매개변수 | 호출 예 | 함수 안에서의 동작 |
| --- | --- | --- |
| `T value` | `f(obj)` | 별도 매개변수 객체를 사용한다. 기존 객체를 넘기면 복사되며, 매개변수를 바꿔도 원본은 그대로다. |
| `T* ptr` | `f(&obj)` | 주소를 값으로 전달한다. 유효한 포인터를 역참조해 원본에 접근할 수 있다. |
| `T& ref` | `f(obj)` | 원본에 직접 연결된다. `ref`에 대입하면 원본이 바뀐다. |
| `const T& ref` | `f(obj)` | 기존 객체를 복사하지 않고 읽을 때 쓴다. 이 참조로는 원본을 수정할 수 없다. |

`swap(int a, int b)`는 복사한 두 값만 바꾼다. `swap(int* a, int* b)`에서는 `*a`와 `*b`를 바꾸고, `swap(int& a, int& b)`에서는 `a`와 `b`에 직접 대입해 원본을 바꾼다. 원 객체도 같은 원리로 `readRadius(Circle& circle)`에서 입력한 반지름을 원본에 반영할 수 있다.

### 실습 · 평균 계산 결과와 성공 여부 전달

반환값으로 성공 여부를 전달하고, 평균은 참조 매개변수 `result`에 쓴다. 예를 들어 `{-1, 1}`의 평균이 `0`인 경우와 원소 개수가 잘못된 경우를 구별할 수 있다.

```cpp
bool average(const int scores[], int count, double& result) {
    if (count <= 0) {
        return false;
    }

    double sum = 0;
    for (int i = 0; i < count; ++i) {
        sum += scores[i];
    }
    result = sum / count;
    return true;
}
```

수정 가능한 참조를 반환하는 함수는 대입문의 왼쪽에도 올 수 있다. 예를 들어 `char& first(std::string& text) { return text.front(); }`를 정의하고 비어 있지 않은 `name`에 `first(name) = 'S';`를 실행하면 원본의 첫 글자가 바뀐다. 함수가 끝날 때 소멸하는 지역 변수의 참조를 반환하면 이후 그 참조로 유효한 객체에 접근할 수 없다.

## 복사 생성자와 객체 반환

- `Circle b = a;`와 `Circle b(a);`는 기존 객체 `a`로 새 객체 `b`를 초기화한다. `b = a;`는 이미 생성된 객체에 대입하므로 복사 대입 연산자를 호출한다.
- 컴파일러가 제공하는 복사 생성자는 멤버별로 복사한다. `int` 멤버는 값이 복사되고, 원시 포인터 멤버는 주소가 복사된다.
- **얕은 복사**로 동적 메모리의 주소만 복사하면 두 객체가 같은 메모리를 가리킨다. `Person` 실습에서 사본의 이름을 바꾸자 원본 이름도 함께 바뀌었다. 두 소멸자가 같은 배열을 해제하려 하면 이중 해제가 발생한다. 한 객체의 포인터만 `nullptr`로 바꿔도 다른 객체의 포인터는 그대로다.
- **깊은 복사**는 사본 전용 공간을 할당하고 내용을 복사한다. C 문자열을 복사할 때는 끝의 널 문자까지 포함하도록 `std::strlen(name) + 1`바이트를 확보한다.

```cpp
#include <cstddef>
#include <cstring>
#include <iostream>

class Person {
public:
    explicit Person(const char* name) {
        const std::size_t length = std::strlen(name) + 1;
        name_ = new char[length];
        std::memcpy(name_, name, length);
    }

    Person(const Person& other) : Person(other.name_) {}
    Person& operator=(const Person&) = delete;

    ~Person() {
        delete[] name_;
    }

    void setInitial(char letter) {
        if (name_[0] != '\0') {
            name_[0] = letter;
        }
    }

    const char* name() const {
        return name_;
    }

private:
    char* name_;
};

int main() {
    Person original{"Grace"};
    Person copy = original;
    copy.setInitial('T');
    std::cout << original.name() << ' ' << copy.name() << '\n';
}
```

출력은 `Grace Trace`다. 예제에서는 복사 생성만 실습하도록 복사 대입을 막았다. 이름을 `std::string` 멤버로 저장하면 문자열의 메모리 관리와 복사를 표준 라이브러리에 맡길 수 있다.

객체를 값으로 반환하더라도 복사 생성자 호출 횟수는 반환식에 따라 달라진다. C++17 이상에서 `Circle` 반환 함수가 `return Circle{3};`처럼 같은 타입의 값을 직접 반환하면 결과 객체가 직접 생성된다. `Circle c{3}; return c;`처럼 이름 있는 지역 객체를 반환하면 컴파일러가 NRVO를 적용해 복사나 이동을 생략할 수 있다. 수업에서는 Visual Studio에서 생성자와 소멸자 로그를 찍어 호출 순서를 비교했다.

## 함수 오버로딩과 기본 인수

- **함수 오버로딩**은 같은 이름에 다른 매개변수 목록을 두는 것이다. 예를 들어 `big(int a, int b)`는 두 정수 중 큰 값을, `big(const int values[], int count)`는 배열의 최댓값을 구한다. 반환형만 바꾸면 오버로딩할 수 없다.
- 생성자도 오버로딩할 수 있다. 소멸자는 매개변수가 없는 형태 하나만 사용한다.
- **기본 인수**는 호출에서 생략된 뒤쪽 인수를 채운다. `void star(int count = 5);`에서 `star()`는 `star(5)`와 같다. `void msg(int id, const std::string& text = "Hello");`에서는 `msg(10)`이 가능하고 `msg()`에는 필수 인수 `id`가 빠져 있다.
- 헤더와 구현 파일을 나눌 때는 호출하는 쪽에서 볼 수 있는 헤더의 선언에 기본값을 적고, 구현 파일의 정의에서는 기본값을 반복하지 않는다.
- `Circle()`과 `Circle(int radius)`의 동작은 `explicit Circle(int radius = 1);`로 합칠 수 있다. 인수 없이 부를 수 있는 별도 생성자를 함께 두면 `Circle c;`에서 어떤 생성자를 부를지 모호해진다.
