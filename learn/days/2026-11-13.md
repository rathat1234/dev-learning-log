## 함수 오버로딩이 모호해지는 경우

컴파일러는 호출에 사용할 수 있는 후보 중 각 인수에 필요한 변환을 비교한다. 가장 적합한 후보를 하나로 고를 수 없으면 컴파일 오류가 난다.

| 원인 | 예 | 해결 방법 |
| --- | --- | --- |
| 암시적 형 변환 | `square(float)`와 `square(double)`에 `square(3)`을 호출하면 `int`를 두 타입으로 변환할 수 있다. | `square(3.0f)` 또는 `square(3.0)`으로 인수 타입을 지정하거나 정수용 오버로드를 둔다. |
| 값과 참조 매개변수 | `f(int)`와 `f(int&)`가 있을 때 `int n`에 대해 `f(n)`은 두 후보에 모두 맞는다. | 호출 목적에 따라 함수 이름을 구분하거나 매개변수 목록을 다르게 설계한다. |
| 기본 인수 | `msg(int)`와 `msg(int, std::string = "Good morning")`가 있으면 `msg(6)`은 두 후보를 모두 만족한다. | 한 인수로 호출할 형태를 하나만 남긴다. |

객체를 읽기만 할 때는 `const T&`로 받아 복사를 피할 수 있다. 호출한 쪽의 객체를 수정하는 함수에는 `T&`를 쓴다.

## `static` 멤버와 객체 개수 세기

- 비정적 데이터 멤버는 객체마다 따로 있고, `static` 데이터 멤버는 모든 객체가 하나를 공유한다. 실습에서는 공금은 `static`, 개인이 가진 돈은 비정적 멤버로 두었다.
- `Circle::getNumOfCircles()`처럼 클래스 이름으로 정적 멤버 함수에 접근할 수 있다. 객체 없이 호출할 수 있으며, `private` 정적 데이터는 클래스 내부에서 관리한다.
- 정적 멤버 함수에는 `this`가 없다. 비정적 멤버를 사용하려면 매개변수 등으로 접근할 객체를 지정한다. 비정적 멤버 함수는 정적 멤버에도 접근할 수 있다.
- 클래스 안에 `static int count;`를 선언했다면 보통 `.cpp` 한 곳에 `int Circle::count = 0;`으로 정의한다. C++17부터는 클래스 안에서 `inline static int count = 0;`으로 정의할 수도 있다.

`Circle` 실습에서는 생성할 때 공유 카운터를 증가시키고 소멸할 때 감소시켰다. 서로 다른 블록에서 객체를 만들면 블록을 벗어날 때 카운터가 줄어들어 현재 살아 있는 객체 수를 확인할 수 있다. 복사 생성도 허용하는 클래스라면 복사로 만든 객체도 집계해야 한다.

## `friend`로 비공개 멤버 접근 허용하기

클래스 내부의 `friend` 선언은 선택한 함수나 클래스에 `private`과 `protected` 멤버 접근을 허용한다. 수업에서는 `Rect`의 너비와 높이를 비교하는 `equals`와, 한 사각형의 치수를 다른 사각형에 복사하는 `copy`를 살펴봤다.

| 선언 예 | 접근 권한을 받는 대상 |
| --- | --- |
| `friend bool equals(const Rect&, const Rect&);` | 외부 함수 `equals` |
| `friend bool RectManager::equals(const Rect&, const Rect&);` | `RectManager`의 지정된 멤버 함수 하나 |
| `friend class RectManager;` | `RectManager`의 모든 멤버 함수 |

두 번째 방식에서는 `class Rect;`로 먼저 이름을 선언하고, `RectManager`에 `equals`의 원형을 선언한 뒤, `Rect`에서 그 함수를 `friend`로 지정한다. 실제 비교 코드는 `Rect`의 정의를 볼 수 있는 위치에 둔다. 비교 대상은 `const Rect&`, 치수를 복사받아 바뀌는 대상은 `Rect&`로 받는다.

## 연산자 오버로딩 · `Power` 실습

`a + b`를 멤버 연산자로 구현하면 `a.operator+(b)`에 해당하고, 비멤버 연산자로 구현하면 `operator+(a, b)`에 해당한다. `2 + a`처럼 왼쪽 피연산자가 `int`인 식은 `Power`의 멤버 함수로 구현할 수 없으므로 비멤버 연산자를 사용한다. 비멤버 함수에 비공개 멤버 접근이 필요할 때 `friend`를 쓴다.

- 같은 `a + b` 호출에 대해 멤버와 비멤버 연산자가 모두 똑같이 잘 맞으면 모호해진다. 수업에서는 두 구현을 번갈아 사용해 차이를 확인했다.
- 피연산자 중 하나는 클래스 또는 열거형이어야 한다. 연산자를 오버로딩해도 우선순위와 결합 방향, 피연산자 개수는 그대로다. `.`과 `::` 같은 연산자는 오버로딩할 수 없다.
- `+`는 합을 새 값으로 반환하고, `+=`는 왼쪽 객체를 수정한 뒤 그 객체의 참조를 반환한다. `==`는 `kick`과 `punch`가 모두 같은지 `bool`로 반환한다.
- 전위 `++a`는 증가 후 자기 자신의 참조를 반환한다. 후위 `a++`는 증가 전 값을 복사해 반환하며, 추가 매개변수 `int`로 전위와 구분한다. 비멤버 형태는 각각 `operator++(Power&)`, `operator++(Power&, int)`다.

```cpp
#include <iostream>

class Power {
public:
    Power(int kick, int punch) : kick_(kick), punch_(punch) {}

    Power operator+(const Power& rhs) const {
        return Power{kick_ + rhs.kick_, punch_ + rhs.punch_};
    }

    Power& operator+=(const Power& rhs) {
        kick_ += rhs.kick_;
        punch_ += rhs.punch_;
        return *this;
    }

    bool operator==(const Power& rhs) const {
        return kick_ == rhs.kick_ && punch_ == rhs.punch_;
    }

    Power& operator++() {
        ++kick_;
        ++punch_;
        return *this;
    }

    Power operator++(int) {
        Power before = *this;
        ++(*this);
        return before;
    }

    Power& operator<<(int amount) {
        kick_ += amount;
        punch_ += amount;
        return *this;
    }

    void show() const {
        std::cout << '(' << kick_ << ", " << punch_ << ")\n";
    }

    friend Power operator+(int lhs, const Power& rhs) {
        return Power{lhs + rhs.kick_, lhs + rhs.punch_};
    }

private:
    int kick_;
    int punch_;
};

int main() {
    Power a{1, 2};
    const Power b{2, 3};
    (a + b).show();            // (3, 5)
    (2 + a).show();            // (3, 4)
    (a++).show();              // (1, 2)
    (++a).show();              // (3, 4)
    (a += b).show();           // (5, 7)
    std::cout << std::boolalpha << (a == Power{5, 7}) << '\n';

    Power c{1, 2};
    (c << 3 << 5 << 6).show();  // (15, 16)
}
```

`operator<<(int)`는 이 실습에서 두 능력치에 정수를 더하도록 정의했다. `(c << 3) << 5`처럼 같은 객체에 연속해서 적용할 수 있는 이유는 반환형이 `Power&`이기 때문이다. `std::cout << a << b`도 첫 출력 연산이 스트림 참조를 반환해 이어진다.

오른쪽 매개변수의 `const Power&`는 `const` 객체와 임시 객체도 받을 수 있게 하고, 함수 선언 끝의 `const`는 `const`인 왼쪽 객체에서도 해당 멤버 함수를 호출할 수 있게 한다. 수업에서는 생성자 로그도 비교했다. `return result;`로 이름 있는 지역 객체를 반환하면 NRVO로 복사나 이동이 생략될 수 있다. 위 `return Power{...};`처럼 같은 타입의 값을 직접 반환하면 C++17부터 결과 객체를 직접 생성한다. 수명이 끝나는 지역 객체의 참조를 반환하면 안 된다.

## 상속의 시작 · `Point`와 `ColorPoint`

`class ColorPoint : public Point`는 좌표를 다루는 `Point`를 기본 클래스로 두고 색상 멤버와 관련 함수만 추가한다. `Point`에 둔 `x`, `y`가 `private`이면 `ColorPoint`에서도 직접 접근할 수 없으므로 기본 클래스의 `set()`과 `showPoint()`를 이용한다. `Point p;`로 만든 별도 객체와 `ColorPoint cp;` 안에 들어 있는 `Point` 부분은 각각 독립된 상태를 가진다.

| `Point`의 멤버 | `public Point` | `protected Point` | `private Point` |
| --- | --- | --- | --- |
| `public` | 파생 클래스에서도 `public` | 파생 클래스에서 `protected` | 파생 클래스에서 `private` |
| `protected` | 파생 클래스에서도 `protected` | 파생 클래스에서도 `protected` | 파생 클래스에서 `private` |
| `private` | 파생 클래스에서 직접 접근 불가 | 파생 클래스에서 직접 접근 불가 | 파생 클래스에서 직접 접근 불가 |

예를 들어 `Point::set()`이 `public`이면 공개 상속에서는 `main()`의 `cp.set(3, 4)`가 가능하다. 보호 또는 비공개 상속으로 바꾸면 `ColorPoint` 내부에서는 `set()`을 호출할 수 있지만 외부의 `cp.set(3, 4)`는 막힌다. 별도 `Point` 객체의 `p.set(3, 4)`는 계속 호출할 수 있다.
